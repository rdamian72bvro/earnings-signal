# earnings-signal-ui

Angular MVP UI for the Earnings Signal Generator.

## Development

```bash
npm install
npm run start
```

`npm run start` proxies `/api/*` requests to `http://localhost:5086`.

## Build

```bash
npm run build
```

## Current MVP page

- Weekly Scanner table (`/api/earnings/upcoming`)
- Live Signals section (`/api/signals/live`)
